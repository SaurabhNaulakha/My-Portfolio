# Saurabh Naulakha — Portfolio

Personal portfolio of **Saurabh Naulakha**, Full Stack Developer.

This project is based on a 3D React/Vite portfolio template and has been personalized in place.

## Run locally

```bash
npm install
npm run dev
```

## Contact form

Copy `.env.example` to `.env` and add your EmailJS values:

- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`

The resume PDF is served from `public/Resume.pdf`.
